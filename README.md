# 🚀 Smart Elevator Safety Monitoring System

An IoT-based elevator safety monitoring system that uses an ESP32 and multiple sensors to detect unsafe conditions, monitor elevator status in real time, and provide instant alerts through a Node-RED dashboard.

## 📖 Overview
This project aims to improve elevator safety by continuously monitoring critical parameters such as passenger presence, door obstruction, motion, temperature, humidity, and emergency events. The collected data is transmitted wirelessly via MQTT for real-time visualization and monitoring.

## ✨ Key Features
- Real-time elevator monitoring
- Passenger presence detection
- Door obstruction detection
- Motion and sound detection
- Temperature & humidity monitoring
- Wireless communication using MQTT
- Node-RED dashboard for live monitoring
- Instant alert generation
